**Виконав Костюк Артем, група КН-42**

## Тема

Інтеграційне тестування

### Мета роботи

Перевірити взаємодію HTTP, логіки програми, SQLite і JSON у Flask та операції SQLite в матеріалах групи.

---

### Виконання роботи

1. [Застосунок Flask](../../example/testing/04_integration_testing/app.py) тестується через `test_client()`. Кожен тест отримує власні SQLite і JSON у `tmp_path`. Прийнятий POST повертає **201**, GET повертає **200**, відсутній або неправильний `title` повертає **400**.
2. [Тести](../../example/testing/04_integration_testing/test_app.py) звіряють тіло HTTP-відповіді, фактичні записи SQLite та експортований JSON. Перевірено порожній експорт, відновлення пошкодженого JSON і порядок двох завдань за ID.
3. Маршрут `DELETE /tasks/<int:task_id>` повертає **204** і прибирає запис із SQLite та JSON. Повторне видалення відсутнього запису повертає **404**. Тест перевіряє, що другий запис залишається доступним.
4. У [груповому прикладі](integration) перевірено `Student`, `Group`, додавання, читання і видалення записів у SQLite. [Перевірка SQLite](integration/tests/test_sql.py) читає збережені поля через запит до тимчасової бази. Демонстраційна програма додала п’ять записів, потім видалила їх. [Вивід програми](results/04-group-program.txt).

```bash
# Залежності в корені проєкту
poetry install

# Із кореня проєкту
poetry run pytest example/testing/04_integration_testing -v
poetry run pytest testing/4_lab/integration -v
poetry run pytest -m integration -v
```

Пройшли [11 тестів Flask](results/04-teacher.txt) і [7 групових тестів](results/04-group.txt). Юніт-тест `Student` перевіряє один об’єкт. Інтеграційні тести проходять від HTTP або об’єкта `Student` до фактичних даних у SQLite та файловому експорті, якщо він є частиною сценарію.

---

### Висновок

Мету досягнуто. Перевірено узгодженість відповіді, бази й файлу, включно з помилковими даними та видаленням. Тимчасові ресурси дають змогу повторювати сценарії без впливу на інші тести. Окремі перевірки стану допомагають визначити, на якому рівні виникла помилка.
