# Звіт до роботи 1

**Виконав Костюк Артем, група КН-42**

## Тема

Загальне тестування та юніт-тести

### Мета роботи

Перевірити введення, властивості об’єктів і винятки засобами unittest.

---

### Виконання роботи

1. У [прикладі Figure](../../example/testing/01_general_and_unittest/app.py) вручну створено квадрат, прямокутник і трикутник. Значення `get_figure_type` і `get_figure_length` відповідають заданим даним. [Вивід перевірки](results/01-manual.txt).
2. Поточний приклад викладача вже містив активний тест довжини та виправлену властивість. Для відтворення вправи у тимчасовій копії відновлено [помилку з попередньої версії методички](https://github.com/BobasB/it_college/blob/9409ec7a79620d709a7d9130423c530b17985001/notes/07_testing/README.md), де властивість повертала тип фігури. Тест очікував `5` і отримав `"квадрат"`. Після повернення `self.length` він пройшов. [До виправлення](results/01-length-before.txt) · [Після](results/01-length-after.txt).
3. У [test.py](../../example/testing/01_general_and_unittest/test.py) перевірено кількість кутів усіх трьох типів, невідомий тип, нульову та від’ємну довжини. `subTest` показує, для якої фігури або рядка виникла помилка.
4. У [validation.py](../../example/testing/01_general_and_unittest/validation.py) введення `7` дає число `7`. Для `0`, `-5`, `abc` і `1.5` функція піднімає `ValueError`. `patch("builtins.input")` дозволяє перевірити обидва сценарії без ручного введення. Підрахунок голосних перевірено на англійському й українському тексті, порожньому рядку та цифрах.
5. У [груповій картковій грі](src/lab1/game.py) додано перевірку `-1.5`. Початковий код спершу перевіряв знак і видавав `ValueError`. Після перевірки типу перед знаком отримано очікуваний `TypeError`. Випадковість атаки замінено під час тесту через `patch`, щоб тест здоров’я проходив повторювано. [Початкова помилка](results/01-group-before-fix.txt) · [Груповий запуск](results/01-group-final.txt).

```bash
# Команди з кореня репозиторію
poetry install
cd example/testing/01_general_and_unittest
poetry run python test.py
poetry run python -m unittest -v

# Окремий запуск матеріалів занять із testing/1_lab
PYTHONPATH=src poetry run python -m unittest tests.test_game_unittest -v
```

Фінальний [запуск Figure і введення](results/01-teacher-final.txt) пройшов 9 тестів. [Автоматичне виявлення](results/01-discovery.txt) також пройшло 9 тестів. У груповому запуску пройшло 9 тестів.
